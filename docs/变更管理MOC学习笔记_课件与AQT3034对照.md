## 一、标准整体框架

- AQ/T 3034-2022 共 **20 个管理要素**（4.1 安全领导力 → 4.20 体系审核与持续改进），替代 2010 版；新增安全领导力、安全生产责任制、合规性管理、装置安全规划与设计、装置首次开车安全、安全仪表管理、重大危险源管理等要素。
- **变更管理为 4.15**，与风险管理（4.6）、安全生产信息管理（4.4）、设备完好性（4.10）、作业许可（4.13）、事故事件管理（4.17）强关联。
- **附录 A.10** 是变更管理落地工具包：A.16 变更事项示例表、A.17 变更申请审批表、A.18 风险识别表、A.19 变更关闭确认表、A.20 变更管理登记台账、A.21 同类替换与变更范例表。

## 二、变更管理的重要性（课件第一章）

- **经典案例：1974 年英国 Flixborough 蒸气云爆炸**
  - 5# 反应器裂纹渗漏被拆除，维修人员用粉笔草图设计 20 英寸临时管道连接 4#、6# 反应器，无机械工程师把关、未做应力分析；
  - 膨胀节破裂，泄漏约 40 t 易燃物料，蒸气云爆炸，28 人死亡，大火燃烧 10 天；
  - 直接催生变更管理（MOC）制度与欧洲 Seveso 指令。
  - 深层诱因：5# 反应器开裂本身也是临时变更造成——临时冷却水管含硝酸盐，加速裂纹腐蚀。
- 权威统计：**变更管理与事故的关联占比约 80%**，为 PSM 各要素中最高（其他要素 28%~60%）。

## 三、定义与分类（规范 4.15.1、4.15.2）

**制度五项最低内容（4.15.1）**：纳入变更管理的范围、变更分类分级原则、管理职责和程序、变更风险辨识及控制、变更实施及验收。

**变更定义**：任何扩增、改造或**非同类替换**的改变，以及经过评审的管理方式和人员情况的调整。

**分类四维度（4.15.2.2 / 4.15.2.3）**：

| 维度 | 类别 |
|---|---|
| 专业（11 类） | 总图、工艺技术、设备设施、仪表系统、公用工程、管理程序和制度、组织架构、生产组织方式、重要岗位人员和职责、供应商、外部条件 |
| 期限 | 永久性 / 临时性 |
| 流程 | 常规 / 紧急 |
| 风险 | 一般 / 重要 |

**同类替换（4.15.2.4）**："同类替换可不执行变更管理程序"——全条唯一豁免项。判定标准（A.21）：同供应商、符合原设计规格同一型号、**同类型、同材料、同压力等级、同尺寸、同填料**，且不修改设计规格文件、对功能与安全无不利影响。识别错误 = 把变更当替换放行。

## 四、变更分级（四川省应急管理厅川应急规〔2025〕1 号，课件重点）

| 级别 | 典型情形 | 流程 |
|---|---|---|
| 一类变更 | 周边条件重大变化、变更建设地址、主要工艺路线/产品方案/装置规模重大变化（同类装置规模扩大 20% 及以上）、重大危险源数量增加或等级提升 | 重新安全评价 + 安全设施设计 + 安全条件审查、设计审查 |
| 二类变更 | 主要工艺流程或主要设备技术规格变更、新增主要建构筑物/装置/罐区、总体布局变化、主要反应设备容积增加、SIL 降低、供电负荷等级降低 | 安全设施变更设计 + 设计变更专篇 + 原审查单位审查 |
| 三类变更（14 种） | 辅料品种/用量变化、主要反应设备更换但不增容积、工艺参数超原设计范围但安全性未降低、硝化/氯化/氟化/重氮化/过氧化工艺风险评估范围变化等 | 设计单位出具设计变更文件 + 企业自主评审 |
| 四类变更 | 一~三类之外 | AQ/T 3034 + 企业内部制度 |

**原则**：多个变更就高不就低；不得拆分变更事项规避分级；无法确定等级的，委托设计单位出具变更等级意见，由原审查单位确认。

## 五、管理程序八环节（规范 4.15.3~4.15.8）

| 环节 | 规范条款 | 课件实操要点 |
|---|---|---|
| 1. 变更申请 | 4.15.4 | 先做必要性评估；申请表写明原因、目的、类别、潜在风险及措施、时间、内容方案、相关方、预期效果、需更新文件。**预期目标必须可测量**（错例"提高烧碱产量"；正例"月产 2000 吨提至 2200 吨"）；文件更新具体到图纸编号与章节 |
| 2. 风险评估 | 4.15.5 | 所有相关专业参与、具备能力经验、必要时请外部专家；方法：SCL / HAZOP / What-if / FMEA / QRA。**实施过程风险与变更后风险不能相互替代** |
| 3. 变更审批 | 4.15.6 | 审查三件事：流程符合性、评估准确性、措施有效性；**对批准方案的任何改变须重新执行变更程序**（4.15.6.3）。金句：不要用行政审批替代专业审批；不要用费用大小替代风险大小 |
| 4. 变更实施 | 4.15.7.1-2 | 严格按批准内容和范围实施；相关资料与操作规程审查、修改、更新、归档 |
| 5. 培训告知 | 4.15.7.3 | 覆盖本企业人员、承包商、供应商、外来人员；内容包括变更目的、内容、操作方法、风险、管控措施、同类事故案例 |
| 6. 变更验收 | 4.15.8.1 | 验收含**变更与预期效果符合性评估**；**验收 ≠ 关闭**——关闭前必须回顾全过程，所有安全措施/行动项闭环（A.19） |
| 7. 资料归档 | 4.15.8.2 | 档案至少含申请审批表、风险评估记录、实施资料、关闭确认记录 |
| 8. 变更关闭 | A.19 | 关闭四前提：培训全部完成、风险评估建议项全部关闭、PSSR 问题关闭、验收达到预期效果 |

### 临时变更（4.15.3.4）

- 申请时明确恢复原样的期限；**未经审查批准，不得超过原批准范围和期限**；
- 课件企业标准：最长 6 个月，只能延期一次再 6 个月（需原批准人批准 + 重新风险分析）；到期恢复原样（记入台账）或转永久变更（重新风险评估）。

### 紧急变更（4.15.3.5）

- 规范要求"尽可能减少和避免紧急变更"；
- 流程：现场负责人采取必要风险控制措施 → 相关负责人审批（可口头）→ 实施 → 及时检查确认风险控制措施 → **48h 内补办全部手续**（申请、分级、风险评估、批准、资料、PSSR 记录、培训、验收关闭）；
- 课件补充：48h 内同步按事件管理制度调查分析、编制事件报告；监测紧急变更占比，防止"走捷径"常态化。

## 六、管理要点（课件第三章，T/CCSAS 007-2020 展开）

1. **识别同类替换与变更**（T/CCSAS 007 附录 C）：碳钢换不锈钢（氯化物点蚀）、壁厚 8mm→10mm（应力分析失效）、球阀换闸阀（操作规程失效）、单密封换串联密封、离心泵临时换容积泵（需泄压路径）、润滑油牌号不同均为变更。**利旧设备、临时管线、报警联锁改值为高发遗漏区**。
2. **易忽略的变更**：金属垫片换四氟、塑料管换金属管（静电）、临时设备/管道/阀门、等体积不同长径比反应器、改变容器用途、泵叶轮加大、带压堵漏夹具等 8 类。
3. **流程适配企业**：全员有提申请权限（文化）；全员培训（能力）；流程统一而不复杂；**审批权看专业能力而非职位**；信息化软件只是工具。
4. **理解原设计意图与保护层作用**：案例——气动切断阀故障模式 FC 被利旧换成 FO，两年后清理管线碰断气源管，阀门自动打开喷酸伤人。故障安全模式是保护层，更换即变更。
5. **PSSR 不可缺**：按变更复杂程度分级设置，简单的可以作业许可验收或投用前检查替代，不一刀切。
6. **三级培训**：所有员工认知培训 / 相关人员基础培训 / MOC 关键角色专项培训。

## 七、指标与审计（规范 4.20 + 课件第四章）

**运行指标**：变更导致的事故数；错误归类为同类替换的比例；未正确审查/记录的比例；工艺安全信息未更新比例；培训缺失比例；紧急变更占比及变化量。

**效率指标**：申请到批准平均时长；行动项完成平均时长；积压申请数；所需人时。

**符合性审计（4.20）**：规范要求全面过程安全管理审核**至少每三年一次**，其间非正式审核可每月至每年一次；课件实操为跨专业团队 + 审计检查表逐项打分（某企业 48 项条款，实际合格率仅 32%~42%——"审计结果会让我们大吃一惊"）。

**审计案例**：利旧闲置 2 年的再沸器作备用再沸器——未取得原设计单位同意、原始资料与注册登记信息不明、未做强度试验和检验、未办安装监检手续，行动项均未明确。

## 九、行动自查清单

1. 对照 4.15.1 检查变更制度五项内容是否齐全；
2. 用 A.16 示例表自查漏管变更类型（重点：联锁摘除、DCS 组态、量程变化、利旧设备、临时管线）；
3. 用 A.19 关闭确认表核对历史变更是否真闭环；
4. 按 4.15.3.4/3.5 对临时/紧急变更设台账期限预警（6+6 个月、48h 补办）；
5. 审批权限表核对：是否存在用行政审批替代专业审批的情形；
6. 按 4.20 排查三年期内是否做过符合性审计，没有则列入年度计划。
